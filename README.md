 # Mood-Matcher

SPA TV show recommendation app that suggests what to watch based on your current mood.

## How to Use

1. Select a mood from the dropdown menu
2. Browse your personalized show recommendations
3. Hover over a card to see more details about a show
4. Click the checkmark to save a show to your watchlist
5. Click the X to dismiss a show and get a new recommendation

## Features

- Mood-based TV show recommendations
- Flippable show cards with detailed information
- Personal watchlist to save shows you are interested in
- Continuously refreshed recommendations as you browse

## API

[TVMaze API](https://www.tvmaze.com/api) 
https://api.tvmaze.com/shows
